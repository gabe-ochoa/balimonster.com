# Brand-first landing prototypes
Use existing React static export and local trip photos. Move the existing homepage to /spearfishing. Add /charters. Set each branch's app/concept.ts to popup, split, or activity. Share all destination code. No new dependency, backend, cookies, or stored preferences.

Popup: native dialog opens on homepage load; two paths and an explicit close control. Repeats on reload intentionally for review.
Split: two image choices directly on the page, equal visibility with slightly larger charter card.
Activity: scenic hero prioritizes boat days, with a smaller spearfishing link and five activity cards.

Tradeoffs: popup adds interruption; split preserves more spearfishing prominence; activity best addresses the stated concern but makes spearfishing less dominant. No winning production choice until customer review. Only neutral photos appear before a visitor enters spearfishing. Existing gallery remains a spearfishing gallery, linked from that destination only.
